# 🎬 ClipForge — YouTube Video Clipper

A modern web app to clip YouTube long videos into short-form content (Reels, TikTok, Shorts).

![ClipForge](https://img.shields.io/badge/ClipForge-Video_Clipper-6c5ce7?style=for-the-badge)

## ✨ Features

- 🎯 **Multiple Clip Durations** — Choose 30s, 60s, or 90s clips
- 👁️ **Live Video Preview** — Embedded YouTube player with custom controls
- 🎚️ **Interactive Timeline** — Click or drag to pick the exact start point
- ⌨️ **Manual Time Entry** — Type exact minutes and seconds
- 🎬 **Clip Preview** — Preview your clip before exporting
- 📋 **Clips Queue** — Manage multiple clips from the same video
- 📥 **Export with yt-dlp** — Get ready-to-use download commands
- 🌙 **Dark Mode UI** — Beautiful glassmorphic design
- 📱 **Responsive** — Works on desktop and mobile
- ⌨️ **Keyboard Shortcuts** — Space (play/pause), arrows (seek), M (mute)

## 🚀 Quick Start

### Option 1: Open Directly (No server needed!)
Simply double-click `public/index.html` to open in your browser.

> **Note:** The YouTube player requires an internet connection to load videos.

### Option 2: Run with Node.js (optional)
```bash
# Install Node.js from https://nodejs.org
node server.js
# Open http://localhost:3000
```

## 📖 How to Use

1. **Paste a YouTube URL** into the input field
2. **Click "Load Video"** to load the video player
3. **Choose clip duration** — 30s, 60s, or 90s
4. **Set the start time** using:
   - The interactive timeline (click/drag)
   - Manual time entry fields
   - "Use Current Position" button
5. **Preview your clip** to verify it looks good
6. **Export** to get the download command

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Space` | Play / Pause |
| `←` | Seek back 5s |
| `→` | Seek forward 5s |
| `M` | Mute / Unmute |

## 💡 For Actual Video Downloads

The app generates a **yt-dlp** command you can run to download the actual clipped video:

```bash
# Install yt-dlp: https://github.com/yt-dlp/yt-dlp
pip install yt-dlp

# Example command generated by ClipForge:
yt-dlp "https://www.youtube.com/watch?v=VIDEO_ID&t=START" \
  --download-sections "*0:30-1:30" \
  -f "bestvideo[height<=1080]+bestaudio" \
  -o "clip_%(title)s.%(ext)s"
```
